I redesigned and rebuilt non-profit resource directory with 300+ organizations in Webflow following a backwards compatible refactor of directory content and metadata for enhanced search, filter, and information design.

The site enabled Harford Helps to manage all their directory information and site content from a single CMS, and expanded to offer a news/blog, and affiliate initiative pages. 

## Problem space
The Harford Helps non-profit resource directory was struggling to handle the increase in number and diversity of non-profit organizations it housed, with tags that didn't fit or meaningfully represent listings, and UI that didn't allow visitors to easily find or explore the organizations. Any refactoring of the resource directory data to improve the user-experience would need to be backwards compatible to maintain information accuracy.

## Process
I worked in close collaboration with the Harford Helps' founder to understand the gaps she had heard and observed with the resource directory, and supported her to guide refactoring so that it aligned with the needs of the organizations and visitors. The aim was the maximize the value from what information was already there, without starting from scratch. I managed and executed the major metadata refactor, which broke out categories, renamed labels, and standardized existing data.
